# The Virus

Text-based game "The Virus" (Belarusian: "Вірус") by Terracon, translated by Uladzimir Charaukhin (Belarusian: Уладзімір Чараухін), a.k.a. veresk.

The game is in Belarusian, developed for RipURQ, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/#virus_be). See the original Russian version [here](https://github.com/urqw/virus).

The game was first published on March 27, 2020.

Interactive fiction identifier (IFID) of the game which is its MD5 hash: 2ACCC528C7C711DEB176D535CAE77865

## Description

Вы крочыце па калідоры лабараторыі. Праходзіце міма непрацуючага экрана. У яго серабрыстай, крыху пукатай  паверхні люструецца ваша постаць у форме вайсковай аховы. На грудзях бялее бэйджык. Вы ведаеце, што на ім асабісты штрых-код і вашае імя "Ray". Чорт, акрамя ўласнага імя вы нічога больш пра сябе не памятаеце! Хто вы, дзе вы, што тут адбываецца? З усім гэтым вам давядзецца разабрацца! На столі гудуць моцныя светлавыя панэлі.
